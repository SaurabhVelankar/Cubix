# Cubix

This is Cubix, a simple and fun game I developed for learning purposes in Unity when I was an undergrad. This is my first-ever game project, and it was inspired by Brackeys, my favourite gameDev YouTuber.

To play the game, please navigate to Builds/Windows/x86_64/CUBIX!!.exe.

Please note that the game does not currently have a pause menu, so you will need to force quit to exit. I plan to update this feature soon if I ever feel like it.

### Features:
1. Features Physics Based entities, with Collision detection, Velocity and Acceleration based physics
2. Contains 10 levels with moderate difficulty
3. Goal is to control the red cube with the joystick and avoid the blue cubes. You win a level after all cubes are avoided
